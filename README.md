
# Azin Gold

A modern and elegant Persian jewelry gallery website, designed and developed as a front-end portfolio project.

## Live Demo

[View Azin Gold Website](https://nasim-ho.github.io/AzinGold/)

## About the Project

Azin Gold is a jewelry gallery landing page with a modern visual identity, featuring elegant product presentations, curated collections, and a refined shopping-inspired experience.

The website is designed with a Persian RTL layout and a responsive interface for different screen sizes.

## Features

- Fully responsive design
- Persian RTL layout
- Interactive hero section with Swiper slider
- Product cards with hover image transitions
- Jewelry categories and collections
- Custom typography
- Reusable React components
- Optimized images and web fonts

## Built With

- React
- JavaScript
- Vite
- Tailwind CSS
- Swiper

## Getting Started

To run the project locally:

```bash
git clone https://github.com/nasim-ho/AzinGold.git

cd AzinGold

npm install

npm run dev
```

## Production Build

```bash
npm run build
```

## Project Type

Front-end portfolio project. Product information and prices are illustrative and are used for presentation purposes.
